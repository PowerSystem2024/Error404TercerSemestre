🧙‍♂️ LA LEYENDA DE AANG: AVATAR – Juego Interactivo en HTML, CSS y JavaScript
<sub>
Este proyecto es un juego basado en el universo de Avatar: La Leyenda de Aang, en donde puedes seleccionar un personaje y realizar ataques según los elementos.</sub>

## Estructura HTML
<sub>
Se creó una estructura básica en index.html con las siguientes secciones:
h1 con el título del juego.
Sección "Seleccionar Personaje" con inputs tipo radio para elegir entre Zuko, Katara, Aang y Toph.
Botón para confirmar la selección.
Secciones para ataques, mensajes dinámicos y reinicio del juego.</sub>
